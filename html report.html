1. Introduction

This project applies Bayesian Logistic Regression to model a binary outcome variable using Bayesian inference. The objective is to estimate the posterior distribution of regression parameters, evaluate model performance using Bayesian model evaluation criteria, and interpret the results probabilistically.

The analysis is conducted using R with the JAGS engine for Markov Chain Monte Carlo (MCMC) sampling.

2. Model Specification

2.1 Likelihood Function

The likelihood is modeled using a Bernoulli distribution:

\[ y_i \sim \text{Bernoulli}(\pi_i) \]

The success probability \(\pi_i\) is linked to the predictors through the logistic (logit) function:

\[ \text{logit}(\pi_i) = \log\left(\frac{\pi_i}{1-\pi_i}\right) = \beta_0 + \beta_1 x_{1i} + \beta_2 x_{2i} + \beta_3 x_{3i} \]

2.2 Prior Distributions

Weakly informative normal priors are assigned to the regression coefficients:

\[ \beta_0 \sim \mathcal{N}(0, 1) \]

\[ \beta_1 \sim \mathcal{N}(0, 1) \]

\[ \beta_2 \sim \mathcal{N}(0, 1) \]

\[ \beta_3 \sim \mathcal{N}(0, 1) \]

These priors regularize the estimates while allowing sufficient flexibility.

2.3 Posterior Distribution

Using Bayes’ theorem, the posterior distribution of the parameters is given by:

\[ p(\boldsymbol{\beta} \mid \mathbf{y}) \propto p(\mathbf{y} \mid \boldsymbol{\beta}) \, p(\boldsymbol{\beta}) \]

The likelihood function can be written as:

\[ p(\mathbf{y} \mid \boldsymbol{\beta}) = \prod_{i=1}^{n} \pi_i^{y_i} (1-\pi_i)^{1-y_i} \]

Because the posterior distribution does not have a closed-form solution, inference is performed using Markov Chain Monte Carlo (MCMC) sampling.

3. Bayesian Estimation Using JAGS

Bayesian parameter estimation was performed using the JAGS (Just Another Gibbs Sampler) engine through Markov Chain Monte Carlo (MCMC) simulation. Two parallel chains were run to assess convergence. Running multiple MCMC chains from different initial values allows for more reliable assessment of convergence. If all chains converge to the same posterior distribution, this provides stronger evidence that the sampler has adequately explored the parameter space. An initial burn-in period of 1,000 iterations was used to allow the chains to reach the stationary distribution, followed by 2,000 iterations for posterior inference.

library(rjags)
library(coda)
library(caret)

heart <- read.csv("heart.csv")

y <- heart$target

x1 <- as.numeric(scale(heart$age))
x2 <- as.numeric(scale(heart$chol))
x3 <- as.numeric(scale(heart$thalach))

n <- length(y)

data <- list(
  y = y,
  x1 = x1,
  x2 = x2,
  x3 = x3,
  n = n
)

model_string <- "model{
  for(i in 1:n){
    y[i] ~ dbern(pi[i])
    logit(pi[i]) <- beta0 + beta1*x1[i] + beta2*x2[i] + beta3*x3[i]
    like[i] <- dbin(y[i], pi[i], 1)
  }
  beta0 ~ dnorm(0,1)
  beta1 ~ dnorm(0,1)
  beta2 ~ dnorm(0,1)
  beta3 ~ dnorm(0,1)
}"

model_jags <- jags.model(
  textConnection(model_string),
  data = data,
  n.chains = 2
)
## Compiling model graph

## Initializing model

  variable.names = c("beta0","beta1","beta2","beta3"),

)

5. Model Evaluation

Model evaluation was performed using Bayesian model fit criteria and predictive assessment techniques. Information criteria were used to assess out-of-sample predictive performance, while posterior predictive checks were used to evaluate model adequacy.

5.1 Deviance Information Criterion (DIC)

dic.samples(model_jags, n.iter=2000)
## Mean deviance:  1210 
## penalty 3.882 
## Penalized deviance: 1214

The Deviance Information Criterion (DIC) is a Bayesian model comparison metric that balances model fit and complexity. Lower DIC values indicate a better trade-off between goodness of fit and model complexity.

5.2 Watanabe–Akaike Information Criterion (WAIC)

samples_like <- coda.samples(model_jags, "like", n.iter=2000)
likelihood <- do.call(rbind, samples_like)
fbar <- colMeans(likelihood)
Pw <- sum(apply(log(likelihood), 2, var))
WAIC <- -2 * sum(log(fbar)) + 2 * Pw
WAIC
## [1] 1213.979

In the WAIC computation, the term f̄ represents the average likelihood across posterior samples, while Pw corresponds to the effective number of parameters and acts as a penalty for model complexity. WAIC balances goodness of fit and model flexibility, with lower values indicating better expected predictive performance.

5.3 Posterior Predictive Check (PPC)

likelihood <- as.matrix(samples_like)

ppc_stat <- rowSums(likelihood)
obs_stat <- sum(y)

hist(ppc_stat,
     breaks = 30,
     main = "Posterior Predictive Check",
     xlab = "Replicated Statistic")

abline(v = obs_stat, lwd = 2, lty = 2)

Posterior predictive checks assess whether the model is capable of reproducing key features of the observed data. Replicated datasets are generated from the posterior distribution and compared to the observed statistic. When the observed statistic falls within the distribution of replicated values, the model is considered to provide an adequate fit.

6.1 Credible Intervals

The forest plot visualizes posterior means and 95% credible intervals for each regression coefficient. The vertical dashed line at zero represents no effect. Predictors whose credible intervals do not cross zero exhibit stronger posterior evidence of association with heart disease risk.

post <- as.matrix(samples)

post_summary <- cbind(
  mean  = colMeans(post),
  lower = apply(post, 2, quantile, 0.025),
  upper = apply(post, 2, quantile, 0.975)
)

post_summary <- post_summary[c("beta0","beta1","beta2","beta3"), ]

par(mar = c(5,8,2,2))

6.2 Posterior Interpretation

Each regression coefficient is interpreted probabilistically. A coefficient whose 95% credible interval does not include zero is considered to have strong evidence of association with the response variable.
